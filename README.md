# Todo HTTP Server

<details><summary><b>Описание задачи</b></summary>
Создайте HTTP-сервер на Go, который будет обрабатывать следующие эндпоинты:
- POST /todos — создать новую задачу
- GET /todos — получить список всех задач
- GET /todos/{id} — получить задачу по идентификатору
- PUT /todos/{id} — обновить задачу по идентификатору
- DELETE /todos/{id} — удалить задачу по идентификатору

Структура задачи.
Задача должна включать числовой идентификатор, заголовок, описание и признак завершённости.

Хранилище данных:
Требуется реализовать работу с данными без использования внешних хранилищ данных.

Валидация:
При создании и обновлении задачи заголовок не должен быть пустым.
Если валидация не прошла — вернуть статус 400 Bad Request.

Обработка ошибок:
Если задача с указанным идентификатором не найдена — вернуть 404 Not Found.

Тесты:
Напишите unit-тесты
Убедитесь, что обрабатываются основные кейсы: успешное создание, ошибка валидации, дублирование идентификатора

Дополнительно (по желанию):
- Логирование запросов.
- Использование context для таймаутов/отмены.
- Dockerfile для запуска приложения.


В коде программы не должны использоваться сторонние библиотеки (допустимо использование только стандартной библиотеки)

Результат:

- Прислать ссылку на репозиторий на GitHub/GitLab
- В README.md указать как запустить приложение

Что будет оцениваться:

- Качество кода (читаемость, идиоматичность Go, организация проекта)
- Обработка ошибок и крайних случаев
- Наличие и качество тестов
- Следование требованиям
- Дополнительные фичи (если реализованы уместно)

</details>

## Описание
Стандартный TODO HTTP Server, написанный на Go, два месяца назад делал [CLI TODO](https://github.com/byoverr/task-tracker)
- Полностью на стандартной библиотеке Go
- Используется in memory хранилище

## Сборка
### Через Dockerfile
```shell
docker build -t todo-server .
docker run --name todo-app -p 8080:8080 todo-server
# or
# make docker-build-and-run
```
### Стандартный билд
```shell
go build -o bin/main cmd/todo-server/main.go
go run cmd/todo-server/main.go
# or
# make build
# make run
	
```

## Makefile
- `make build` — сборка приложения
- `make run` — запуск локально через Go
- `make docker-build-and-run` — сборка Docker-образа и запуск контейнера
- `make lint` — проверка кода линтером
- `make test` — запуск тестов
## Роуты
| Метод  | URL         | Описание                   |
| ------ | ----------- | -------------------------- |
| GET    | /todos      | Получить список всех задач |
| GET    | /todos/{id} | Получить задачу по ID      |
| POST   | /todos      | Создать новую задачу       |
| PUT    | /todos/{id} | Обновить задачу по ID      |
| DELETE | /todos/{id} | Удалить задачу по ID       |
| GET    | /health     | Проверка состояния сервера |

Есть Postman Collection и OpenAPI, лежат в /docs и /api соответственно
